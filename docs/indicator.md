## Indicator String Format
| Type | Format | Example |
|------|--------|---------|
| Icon | i<characters> | "i💡" |
| Spinner | s<delimiter><characters><delimiter><characters> ... <delimiter><characters><delimiter> | "s\|▱▱▱\|▰▱▱\|▰▰▱\|▰▰▰\|" |


+ Delimiter can be any character not used in spinner characters. So choose the delimiter appropriately.
